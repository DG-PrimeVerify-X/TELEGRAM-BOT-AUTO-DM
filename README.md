# Telegram Admin Bot — Final Multi-Channel Build

## Features
- Multi-channel manager with forwarded-post Add Channel wizard and bot-admin verification.
- Per-channel admin assignment and per-channel automation settings.
- Auto Accept, Auto DM, Auto Post and Auto Reaction.
- 1-minute WinGo prediction module using the supplied HTML's WinGo_1M history endpoint.
- Prediction result tracking: WIN / LOSS / JACKPOT, history and statistics.
- Broadcast to interacted users, user statistics, scheduler, backup and health modules.
- Premium/custom emoji support in Auto-DM where Telegram custom emoji entities are available.
- Public /start dashboard with server-side authorization on admin actions.
- Bottom Contact Us button opens @dragonb98.

## Configuration
Copy `.env.example` to `.env` and set `BOT_TOKEN` and `SUPER_ADMIN_ID`. Owner contact defaults to `dragonb98`.

## Important
Prediction output is a statistical/experimental signal and is not a guaranteed result.
